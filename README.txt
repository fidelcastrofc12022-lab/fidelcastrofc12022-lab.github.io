# Fidel Castro Portfolio

This folder is ready for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year
- `assets/profile-placeholder.svg` — temporary profile image

## Before uploading
1. Replace `assets/profile-placeholder.svg` with your real professional photo.
2. Rename your photo to `profile.jpg`.
3. In `index.html`, change:
   `assets/profile-placeholder.svg`
   to:
   `assets/profile.jpg`
4. If you have a CV, put it in the root folder as `Fidel-Castro-CV.pdf`.
5. If you want a CV button, add it to the hero actions with:
   `<a class="btn secondary" href="Fidel-Castro-CV.pdf" download>Download CV</a>`

## GitHub Pages
Upload all files while keeping the folder structure:
- index.html
- style.css
- script.js
- assets/profile.jpg

Then use GitHub Pages:
Settings → Pages → Deploy from a branch → main → / (root).

Do not change Pages settings if the site is already live.
